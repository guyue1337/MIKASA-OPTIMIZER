# 使用说明

## 启动

- 安装版：双击桌面快捷方式「三笠优选」。
- 便携版：解压后双击 `三笠优选.exe`。
- 首次启动会自动创建数据库，位置见「设置 → 数据目录」。

顶部状态条显示本机省份与运营商，例如：

```
湖北省 · 中国电信
```

若检测失败会显示「网络环境未知」，这不影响测速。点击「重新检测」可重试。

## 1. 导入候选 IP

### 本地文件

支持 TXT、CSV 与拖拽。每行可以是：

```
1.1.1.1
1.1.1.1:443
2606:4700:4700::1111
[2606:4700:4700::1111]:443
```

空行、`#` 注释与常见表头会被忽略。重复的 `IP:端口` 自动合并，来源标签累加。

### 粘贴文本

在文本框中粘贴多行 IP 后点击「解析预览」，确认数量后点击「导入」。不会在导入阶段做任何测速。

### 网络 URL

添加一个返回纯文本或 CSV 的地址，设置自动更新间隔。点击「立即更新」或等待后台定时任务。单个响应最多读取 8 MB。

### FOFA

详见 [FOFA.md](FOFA.md)。选择地区后查询语句自动生成，普通用户无需手写语法。

### Cloudflare 官方 IP 段

选择 IPv4/IPv6、每段抽样数量后点击获取。软件读取 Cloudflare 官方 `ips-v4` / `ips-v6` 列表，按 CIDR 随机抽样，不会做无边界互联网扫描。

### CM IP 库

在「IP 来源 → CM IP 库」点击「自动获取」或分别选择 TXT / JSON。软件读取 `https://zip.cm.edu.kg/all.txt` 或 `all.json`，自动识别 `IP:端口` 与 JSON 的 `data[].ip` / `data[].port` 字段，显示数据更新时间、获取数量、有效 IP、重复与无效数量。自动更新默认开启（每 24 小时），也可手动关闭或调整间隔。网络失败时明确显示错误并允许使用带「缓存」标识的本地副本；CM 的 `country` 只作为候选标签，不等于实际 Cloudflare colo。

## 2. 设置扫描参数

「总览」页可以快速设置：

- 每地区保留数量：10 / 20 / 50 / 100
- 每地区测速数量：前 20 / 前 30 / 前 50 / 前 100 / 全部（默认前 30）
- 测试端口：443 / 80 / 8443
- 并发数量：32 / 64 / 128 / 256
- 延迟上限、下载速度下限、下载时长、最低有效数据量
- 智能补充模式：结果不足时扩大候选池并继续测试

「设置」页提供完整参数，包括 TCP/HTTPS 超时、延迟轮数、最大候选数、测速 URL 与备用 URL。候选来源页还提供社区公开源、来源质量评分与 README 上游发现。

## 3. 开始优选

选择地区后点击「开始优选」。扫描分为四个阶段：

1. TCP 连通性
2. HTTPS 验证与 colo 识别
3. 多轮延迟测试
4. 实际下载速度测试

扫描任务页会实时显示每个地区的漏斗数据。完成前可以取消；取消后已产生的有效结果保留在历史中。

## 4. 查看排名

「地区排名」按地区独立展示。支持：

- 综合评分（速度 60%、延迟 30%、丢包 10%）
- 平均延迟升序
- 下载速度降序
- 丢包率升序

只有完成下载测速且达到阈值的记录才计入正式结果。没有下载速度的记录会标记为失败/不达标，不会出现在正式导出文件。

## 5. 导出

「结果导出」选择目录与格式：

- TXT：选择一个地区生成该地区单个文件；选择「全部地区」生成一个合并文件
- CSV：同样只生成一个文件（单地区或全部地区合并）

TXT 默认格式：

```
104.16.123.45:443#三笠优选 | 香港 | 延迟：42.6ms | 下载：18.35MB/s
```

UTF-8 纯文本，一行一个节点。

## 6. GitHub 上传

详见 [GITHUB.md](GITHUB.md)。上传前可以预览文件；上传失败不影响本地文件。

## 7. 历史记录

- 查看每次扫描的时间、地区、结果数量。
- 查看某次扫描的详细排名。
- 删除单次扫描或清空历史。
- 备份数据库到指定目录，生成完整、可恢复的本地副本。
- 历史 IP 会在下一次扫描中优先复测，但必须重新完成延迟与下载测试，不能沿用旧速度。

## 8. 设置说明

普通设置：默认端口、并发、每地区保留数量、每地区测速数量、界面缩放、延迟/速度阈值、测速时长、自动检测网络、自动更新 IP 列表、默认导出路径。

高级设置：TCP/HTTPS 超时、下载测速 URL、备用 URL、最低有效下载数据量、重试次数、最大候选数、FOFA 模板、colo 映射、代理配置、日志等级。

## 9. 故障排查

| 现象 | 检查 |
|---|---|
| 启动白屏 | 确认 WebView2 已安装；安装版会自动引导 |
| 扫描全部 TCP 失败 | 本地网络、防火墙、端口是否被阻断 |
| HTTPS 成功但 colo 为空 | 测速地址被代理改写，尝试关闭代理/TUN |
| 下载速度一直为 0 | 测速 URL 不可达或最低有效数据量设置过高 |
| FOFA 401/403 | Key、账号权限或配额 |
| GitHub 401/403 | Token 权限或分支保护 |
| 导出为空 | 没有完成下载测速并通过阈值的记录 |

## 10. 数据位置

默认数据库：

```
%APPDATA%\com.mikasa.optimizer\mikasa-optimizer.sqlite
```

「设置 → 打开数据目录」可直接打开。备份文件为完整的本地数据库副本。
