# FOFA 配置说明

FOFA 可以作为候选 IP 来源。导入后的 IP 仍需经过软件的真实 TCP、HTTPS、延迟和下载测速；FOFA 显示的国家只是候选标签，不代表最终机房地区。

## 配置

1. 登录 FOFA，确认账号可以使用 API 查询。
2. 在 FOFA 个人中心获取注册邮箱和 API Key。
3. 打开软件「IP 来源 → FOFA」，填写邮箱与 API Key。
4. 点击「保存配置」。密钥保存在 Windows 凭据管理器中。
5. 选择地区，确认自动生成的查询预览，然后设置本次获取数量。
6. 点击「获取 IP」，完成后到「总览」开始优选。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示无权限 | 确认账号已开通 API，并检查套餐是否支持当前查询字段 |
| 返回数量为 0 | 简化查询条件，确认端口和目标地区正确 |
| 查询成功但测速失败 | FOFA 结果只是候选，必须通过本地网络实测后才会计入正式结果 |
| 想更换 Key | 点击「清除配置」后重新填写 |

API Key 不会写入导出文件或公开文档。请勿把 Key 发到聊天、截图、Issue 或公开仓库。
