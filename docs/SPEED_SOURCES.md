# 测速源说明

软件支持以下下载测速源：

| 选项 | 说明 | 适合场景 |
| --- | --- | --- |
| 自动选择 | 自动检测可用测速源，失败时切换到备用源 | 大多数用户，默认推荐 |
| Cloudflare 官方 | 使用 Cloudflare 官方测速地址 | 海外网络或可正常访问官方测速域名的环境 |
| CM 提供 | 使用 CM 公共测速地址 | 该地址在当前网络可用时 |
| 移动专属 | 面向移动网络优化的测速地址 | 中国移动线路 |
| 手动输入 | 填写自己的 HTTPS 测速地址 | 有稳定自建或第三方测速地址 |

## 选择建议

1. 不确定时保持「自动选择」。
2. 如果预检显示当前测速源不可用，可在「设置 → 测速源」手动切换。
3. 「测速源对比」可以用同一个 IP 分别测试各来源，选择当前网络下更稳定的一组。
4. 只有在下载测速阶段会读取测速文件，候选导入、TCP 和延迟测试不受测速源影响。

## 速度单位

- 软件显示 `MB/s`。
- `1 MB/s = 8 Mbps`。
- v2rayN 等客户端通常显示 `Mbps`，因此同一节点的数值约为软件显示值的 8 倍。

批量测速时，多个 IP 会共用本机出口带宽。若希望结果更接近客户端的单连接速度，可在设置中把「下载测速并发」调为 `1`。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 自动选择后下载速度为 0 | 在设置中执行测速源预检，确认当前网络可访问测速域名 |
| CM / 移动源预检失败 | 该来源在当前地区或运营商下可能不可用，改用自动或 Cloudflare 官方 |
| 速度与客户端差异较大 | 检查下载并发、测速时长、最低有效数据量，并确认客户端显示的是 Mbps |
| 自定义地址不可用 | 必须是 HTTPS，且服务器需允许正常下载测速文件 |
